# Andy Quach Portfolio

Personal portfolio website for showcasing my data engineering, analytics, and software engineering projects.

This portfolio is built with **Next.js**, **TypeScript**, **Tailwind CSS**, and modern React components. It is designed to highlight practical project work, technical skills, certifications, and career progress as I continue building toward data engineering and analytics roles in Canada.
